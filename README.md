## 🎨 About This Project

This is a beautiful, interactive profile website built for my daughter using Vue.js and PrimeVue components. The site features her photo, information, and cute interactive elements.

## 🚀 Quick Start

The website is automatically deployed to GitHub Pages when you push changes to the `main` branch.

### Local Development

1. Navigate to the Vue app:
   ```bash
   cd vue-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173)

4. Build for production:
   ```bash
   npm run build
   ```

### Customization

Edit `vue-app/src/App.vue` to update:
- Daughter's name, age, and birthday
- Hobbies, favorite colors, and fun facts
- Photo URL (currently using the GitHub attachment above)

## 🌐 Deployment

- The site automatically deploys via GitHub Actions
- Visit `https://zhao-ruixi.github.io` to see the live site
- Deployment workflow: `.github/workflows/deploy.yml`
